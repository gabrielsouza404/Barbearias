# Barbearias.UI

> Projeto de UI em Windows Forms - prova de conceito.

## Sobre o projeto

Aplicação desktop criada apenas como prova de conceito para consumo dos serviços do back-end.

O foco do repositório continua sendo no back-end. O projeto existe somente para validar e demonstrar a integração com os serviços.

## Tecnologias

- [C#](https://dotnet.microsoft.com/pt-br/languages/csharp/)
- [.NET](https://dotnet.microsoft.com/pt-br/)
- [Windows Forms](https://learn.microsoft.com/pt-br/dotnet/desktop/winforms/)
